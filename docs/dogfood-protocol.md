# Dogfood Protocol

Use this template when testing the toolkit on Dreamy template projects or real games.

Record for each task:

- project profile
- prompt
- selected skills
- selected agent
- changed files
- verification command
- result
- failure converted into eval, skill, rule, harness, or compatibility update

Do not count a dogfood task as passed without compile, console, test, harness evidence, or an explicit degraded reason.
