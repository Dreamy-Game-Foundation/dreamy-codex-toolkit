# Pattern Selection

Use the smallest pattern that answers a current force.

Need interchangeable algorithms or policies?
Use Strategy.

Need mutually exclusive behavior with transitions, entry, exit, and cleanup?
Use State.

Need notification to multiple independent consumers?
Use Observer or Event Bus.

Need complex or varying creation policy?
Use Factory.

Need to translate an incompatible API?
Use Adapter.

Need a simpler stable entrypoint over a complex subsystem?
Use Facade.

Need non-trivial UI orchestration separated from rendering?
Use MVP-like View plus Presenter or Controller.

No real force?
Use a normal class, direct method call, or existing project convention.
