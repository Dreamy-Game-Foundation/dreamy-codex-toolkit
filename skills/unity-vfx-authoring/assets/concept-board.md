# VFX concept board

Copy/adapt only when concept exploration helps the task. Replace prompt fields with project facts or explicit proposals before generation.

## Prompt template

```text
Create a visual development board for a Unity [2D/3D/UI] [effect purpose].
Art direction: [style and supplied reference roles]. Palette: [colors].
Gameplay camera: [projection, view angle]. Effect footprint: [screen size or units].
Context: [gameplay background and stable subject/scale cue].
Show three panels of the SAME effect: onset at [time], peak at [time],
and dissipating tail at [time], within a proposed total duration of [duration].
Keep camera, pivot, scale and background consistent across all panels.
Layers: [anticipation/flash/ring/sparks/smoke or task-specific layers].
Preserve [target visibility and other constraints]. Avoid [style exclusions].
This is a concept board for choosing visual direction, not a sprite sheet.
```

For variants, change a named design axis such as silhouette or layer structure while retaining the camera and brief. For loops, adapt the panels to onset, sustain and seam/cancel. Record timestamps as proposed until checked in Unity.
